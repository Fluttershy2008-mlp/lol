Revenge Next · Community repository

Fluttershy's plugins
and themes.

21 plugin preview ports and 4 native colour themes, in one repository.

In Revenge Next, open Plugins → Settings → Advanced, paste this into Repository URL, then tap Add repository.

Keep the Revenge Community Plugins repository enabled for the Themes API. Install the previews you use and restart Discord when asked.

These are preview builds. Automated package and adapter checks passed; compatibility on a physical Android device is still unverified.
