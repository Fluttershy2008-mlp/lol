# Sunset Shimmer Chat Background

A companion for the Sunset Shimmer theme on Revenge Classic/Vendetta.

[Theme, installation steps, compatibility, verification, and artwork attribution](../sunset-shimmer/README.md).

Install this folder URL in **Revenge > Plugins**, enable it, and reopen the chat:

```text
https://raw.githubusercontent.com/Fluttershy2008-mlp/lol/main/sunset-background/
```

Use this companion while the Sunset Shimmer theme is active. Disable the Fluttershy wallpaper companion if it is enabled. The image uses the existing Sunset wallpaper on its original host and fills the current chat viewport with no fixed device dimensions.
