The plugin patches native channel-list presentation and row measurements.
Beta3 replaces the Android text alert with a full themed lock screen. The layout
is informed by the user's reference screenshot and Vencord's HiddenChannelLockScreen.
Its lock artwork is drawn with native View styles; no external image is required.
Beta4 resolves missing usernames through Discord's existing HTTP client, supports
modern role-store methods, and opens native profiles when user chips are tapped.
Beta5 adds first-use profile routing through Discord's built-in lazy profile
handler, alternate module export shapes and a Discord-only native URI fallback.
No external web-browser fallback is used.
Beta6 follows Valenced's dependency-aware native profile and link-handler
discovery, uses native stack mode, and adds copyable local profile diagnostics.
Allowed role calculations use Discord's documented permission hierarchy:
https://github.com/discord/discord-api-docs/blob/main/developers/topics/permissions.mdx
Discord's permission checks, channel records and global React factories are not
replaced. No hidden-channel metadata is sent to any third-party service.

Beta11 retains beta10's inspector, settings and profile features. Original channel
list names take priority, row labels use React Native Text, and the native detail
route retains the original list record within the current account. Missing names
may use matching channel/server metadata already held in ChannelStore. No new
network requests or permission changes were introduced for this name fix.
