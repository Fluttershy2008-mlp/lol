Math AI & Scientific Calculator for Valenced
Author: Fluttershy2008-mlp
Inspired by the chat-input workflow of mlemception's Math plugin:
https://github.com/mlemception/mlem-plugins/tree/main/plugins/math
This is a separate implementation with a bounded scientific expression parser,
an optional user-configured AI connection, and answer preview tools.
No upstream arithmetic source or image assets are bundled.
No physical Android device testing has been performed.

Inline currency rates: Frankfurter v2 public API (https://frankfurter.dev/).
Only currency codes are sent. Displayed dates describe the published rates.
The sigma icon is an original geometric image drawn for this plugin.

Version 1.2.0 adds independently implemented offline send-time solving inspired
by mlemception Math. Basic arithmetic fragments in prose and whole scientific
expressions are supported; literals and invalid expressions are preserved.

Version 2.0.0 removes cloud AI and API key configuration. Gemini Nano is
provided by Google's ML Kit GenAI SDK and Android AICore through the Math Nano
companion APK. SDK and service terms: https://developers.google.com/ml-kit/terms
Google SDK setup: https://developers.google.com/ml-kit/genai/prompt/android/get-started
The companion pins kotlinx-coroutines 1.11.0 for the documented Nano download fix.
No model weights or shared cloud credentials are bundled in the plugin.

The currency input renderer follows the source-preserving native span approach demonstrated by the user-provided Inline Markdown Valenced v1.2.0 plugin by fluttershy_simper67. Its currency spans have separate ownership and do not replace the Markdown plugin.
