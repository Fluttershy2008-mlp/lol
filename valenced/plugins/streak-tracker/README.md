# Streak Tracker for Valenced

Refresh the [Valenced repository](https://fluttershy2008-mlp.github.io/lol/valenced/index.json), install **Streak Tracker** from **Browse Plugins**, then fully restart Discord. Open **Settings → Valenced → Streak Tracker** for your stats and preferences.

- Send a message in a one-to-one DM while the plugin is running to mark that day. Each DM can gain one day per calendar day. You have until your phone’s next local midnight to extend a streak from yesterday. Sending after a missed day starts a new streak at one.
- **Messages** shows a fire count alongside tracked DM previews. Counts turn purple at 50 days and red at 100 days. Milestone notifications are available at 10, 50 and 100 days.
- Settings show your active streaks, personal best and five longest active streaks. You can turn badges and notifications off separately or clear the signed-in account’s streak history.
- Tracking starts with new outgoing messages. Streak totals and Discord IDs are stored on this device, separately for each signed-in account. Message text is never stored.

Inspired by [TermitJs’s Streak Tracker for Discord](https://github.com/TermitJs/Streak-Tracker-for-Discord).

The beta package has automated checks for tracking, settings, and the Messages preview hooks. Badge layout on a physical Android device still needs verification.
