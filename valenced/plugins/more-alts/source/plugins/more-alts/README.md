# More Alts!

Manage and switch between multiple Discord accounts seamlessly, with persistent backup storage, token authentication, and automatic native switcher unlocking.

## Automatic Native Account Switching
MoreAlts automatically unlocks Discord's built-in multi-account switcher for mobile without manual evaluation or developer mode commands:
- Automatically hooks MultiAccountStore so Discord activates the YouBar long-press gesture.
- Holding down on your name or avatar in the YouBar displays Discord's native "Switch Accounts" sheet.
- Persistent native vault backup in Android DEX storage prevents accounts from wiping themselves across client restarts.
- Background notification suppression drops notification leaks from accounts not currently active.
- Seamless compatibility with user credentials, Discord authorization tokens, and bot accounts.
