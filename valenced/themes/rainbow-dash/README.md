# Rainbow Dash · Sonic Collage

Rainbow Dash theme and matching font packs for Valenced, by **fluttershy_simper67**.

- Your original portrait collage is included unchanged, centred with the theme renderer's proportional cover fit. Tall phone screens can crop the sides slightly.
- Sky-blue buttons and icons, navy surfaces, cloud-white text, yellow mentions and rainbow status colours.
- **Sonic Collage** keeps the wallpaper visible; **Clear Chat** darkens it further for reading.
- **Rainbow Dash · Sonic** uses Barlow body text and sporty bold italic headings.
- **Rainbow Dash · Clear** uses upright Barlow in five weights.
- All wallpaper and font files are bundled. No font or image downloads are needed after installation.

## Install

Refresh your Valenced repository and update **Rainbow Dash · Sonic Collage** to **1.1.0**, or import the ZIP with Valenced's install-from-file option.

Repository URL:

```text
https://fluttershy2008-mlp.github.io/lol/valenced/index.json
```

1. Enable the plugin, then fully close and reopen Discord.
2. Under **Valenced → Themes → Colors**, choose **Rainbow Dash · Sonic Collage** or **Rainbow Dash · Clear Chat**.
3. Under **Fonts**, choose **Rainbow Dash · Sonic** for the sans and display font selections. Choose **Clear** if you prefer upright headings.
4. Reload Discord to apply fonts to views that were already open.
5. If you previously changed background settings, use **Background → Reset** to apply the new wallpaper defaults. Make sure the background source follows the selected theme.

The theme and fonts can be selected independently. The existing plugin ID and original theme selection ID are retained for updates. Previous ZIP releases remain available.

## Font credits

The font packs use unmodified **Barlow**, by the Barlow Project Authors, under the bundled SIL Open Font License 1.1. This is a Rainbow Dash inspired font setup, not an official My Little Pony typeface. Emoji, icon and monospace families retain their original fallback fonts.

## Validation

Automated validation checks the lexical Valenced registration contract, colour formats and contrast, local asset/font references, exact wallpaper bytes, ZIP integrity, catalogue hashes and deterministic package output. Physical Samsung/Valenced testing is still required to confirm the final display on the phone.
