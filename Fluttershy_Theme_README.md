# Fluttershy - Pink & Yellow

Theme by **Fluttershy2008**. Version **2.0.0**.

Soft pink messages, butter-yellow headings and mentions, dark rose panels, and a G4 Fluttershy chat wallpaper. The theme keeps the rounded Meloso headings and Roboto body font from the supplied theme.

## Install

Copy this URL into your theme import screen:

```text
https://raw.githubusercontent.com/Fluttershy2008-mlp/lol/main/Fluttershy_Pink_Yellow_Theme.json
```

On Revenge versions with **Legacy Themes**, enable that plugin and import the URL in its settings, then select the imported theme. On older versions with a theme `+` button, add the URL there. Reload Discord after selecting it.

To refresh a cached older copy, import the same URL with `?v=2.0.0` added at the end.

## Design

| Element | Colour |
| --- | --- |
| Main panels | `#160F13` |
| Message text | `#F9DDEA` |
| Headings and mentions | `#F6E59B` |
| Links and icons | `#F5B6D1` |
| Input and navigation | `#100B0E` |

The wallpaper uses 28% opacity and light blur to keep text readable. The JSON includes the original theme's optional Themes+ settings and three colour slots for legacy dark, light, and AMOLED modes. The active client and installed theme extensions determine which optional features are supported.
